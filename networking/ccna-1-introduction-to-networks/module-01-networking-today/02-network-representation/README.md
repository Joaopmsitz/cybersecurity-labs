## Step 2

### a. Explain the client-server model.

The client-server model is a network architecture where clients request services or resources and servers provide them. Examples include web servers, email servers, and file servers.

### b. List at least two functions of intermediary devices.

- Forward traffic between devices.
- Determine the best path for data.
- Connect multiple network segments.
- Filter and secure network traffic.

### c. List at least two criteria for choosing network media.

- Cost
- Distance
- Bandwidth requirements
- Environmental conditions
- Resistance to interference

## Step 3

### a. Explain the difference between a LAN and a WAN.

A LAN (Local Area Network) connects devices within a limited geographic area such as a home, office, or school.

A WAN (Wide Area Network) connects multiple LANs over large geographic areas using service provider networks.

### b. How many WANs are visible?

**2 WANs**

- Internet
- Intranet

### c. How many LANs are visible?

**3 LANs**

- Home Office
- Central
- Branch

### d. Briefly describe the Internet.

The Internet is a global collection of interconnected networks that communicate using the TCP/IP protocol suite.

### e. Common ways home users connect to the Internet.

- Fiber
- Cable
- DSL
- 4G/5G
- Satellite

### f. Common ways businesses connect to the Internet.

- Dedicated fiber links
- MPLS
- Metro Ethernet
- VPN services
- Redundant ISP connections
