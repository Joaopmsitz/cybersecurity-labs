# CCNA 1 — Introduction to Networks

> Cisco Networking Academy — CCNA: Introduction to Networks (ITN)

## Overview

Hands-on networking labs and study notes covering network representation, Cisco IOS navigation, switch configuration, network protocols, and the physical layer.

## Labs

| Lab | Description |
|---|---|
| [01 — Physical and Logical Mode Exploration](./01-physical-and-logical-mode-exploration/README.md) | Explore Packet Tracer's Logical and Physical workspaces and understand how network devices and topologies are represented. |
| [02 — Network Representation](./02-network-representation/README.md) | Identify end devices, intermediary devices, and network media; interpret a small-business network topology. |
| [03 — Navigate the IOS](./03-navigate-the-ios/README.md) | Access the IOS command-line interface, explore context-sensitive help and EXEC modes, and practice basic commands. |
| [04 — Console Connectivity with Terminal Client](./04-console-connectivity-with-terminal-client/README.md) | Establish a console connection and use a terminal client to access and interact with a network device's CLI. |
| [05 — Initial Switch Configuration](./05-initial-switch-configuration/README.md) | Inspect the default switch configuration, configure basic access security and a login banner, and save configuration changes. |
| [06 — Basic Connectivity Implementation](./06-basic-connectivity-implementation/README.md) | Implement basic network connectivity by connecting devices, applying required configuration, and checking communication. |
| [07 — Basic Switch and End Device Configuration](./07-basic-switch-and-end-device-configuration/README.md) | Configure switch names and access, assign IP addresses to switches and end devices, save settings, and verify connectivity. |
| [08 — Basic Switch and End Device Configuration — Physical Mode](./08-basic-switch-and-end-device-configuration-physical-mode/README.md) | Apply basic switch and end-device configuration while working with Packet Tracer's physical workspace and device layout. |
| [09 — Investigate the TCP/IP and OSI Models in Action](./09-investigate-tcp-ip-and-osi-models-in-action/README.md) | Use Simulation mode to inspect HTTP traffic, follow protocol data units, and observe encapsulation across network layers. |
| [10 — Connect a Wired and Wireless LAN](./10-connect-a-wired-and-wireless-lan/README.md) | Connect routers, switches, wireless equipment, and end devices using appropriate media; verify connections and inspect the topology. |
| [11 — Physical Layer Exploration — Physical Mode](./11-physical-layer-exploration-physical-mode/README.md) | Trace an IP packet's path from a client to a remote web server and explore the networks and providers involved in delivery. |
| [12 — Connect the Physical Layer](./12-connect-the-physical-layer/README.md) | Inspect device interfaces, select suitable connectivity modules, connect network devices, and verify connectivity. |

## Tools

- Cisco Packet Tracer
- Cisco IOS
- Wireshark
- Git and GitHub
