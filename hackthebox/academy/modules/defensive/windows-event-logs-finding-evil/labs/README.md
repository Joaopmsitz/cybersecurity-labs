# Labs

Practical exercises associated with Windows Event Logs & Finding Evil.

## Exercises

| Lab | Focus |
|---|---|
| [01 — Windows Event Logs](./01-windows-event-logs/) | Windows Security logs, Event Viewer, event correlation, SACL auditing, and XML filtering. |
| [02 — Sysmon Event Analysis](./02-sysmon-event-analysis/) | Sysmon configuration, DLL loading analysis, .NET runtime telemetry, and credential access detection concepts. |
| [03 — Tapping Into ETW](./03-lab-03-tapping-into-etw/) | ETW architecture, Logman sessions and providers, SilkETW collection, Kernel-Process telemetry, and .NET Runtime tracing. |
| [04 — Skills Assessment](./04-lab-04-skills-assessment/) | Practical threat hunting across DLL hijacking, unmanaged .NET execution, process injection, LSASS access, authentication events, and anomalous process relationships. |
