## What I Learned

- How HTB Academy is structured: **Paths → Modules → Sections**
- The difference between **Theory** and **Interactive** sections
- How **Pwnbox** and exercise targets support hands-on learning
- The difference between **Skill Paths** and **Job Role Paths**
- How module completion and **Skills Assessments** work

## Academy Structure

- **Paths** group related modules into structured learning curricula.
- **Modules** cover individual topics.
- **Sections** organize a module into smaller learning units.

## Learning Environment

- **Theory sections** explain concepts and technical procedures.
- **Interactive sections** provide exercises to practice the concepts.
- **Pwnbox** provides a hosted environment for practical activities.
- **Exercise targets** are systems provided for the hands-on tasks described by a module.

## Progress and Assessments

- Track completion through the module sections.
- Complete the required interactive exercises and questions.
- Complete the Skills Assessment when one is provided.
- Confirm that required sections are complete before marking the module finished.
