# HTB Academy — Job Role Paths

> Index of role-oriented HTB Academy learning paths documented in this repository.

## Overview

Job Role Paths organize modules around the knowledge and practical competencies associated with a specific technical role. They emphasize workflows, investigation methodology, tools, and applied skills rather than a single technology.

This category currently documents the SOC Analyst Job Role Path, which prepares learners for security monitoring, threat detection, investigation, and incident handling.

## SOC Analyst Learning Focus

The SOC Analyst path covers practical security operations activities, including:

- Security monitoring, log analysis, and SIEM investigations.
- Windows event analysis, threat hunting, and detection engineering.
- Network traffic analysis and IDS/IPS monitoring.
- Malware analysis and digital forensics.
- Incident handling and security incident reporting.

The path overview, module sequence, estimated duration, and current completion status are documented in the [SOC Analyst README](./soc-analyst/README.md).

## Job Role Paths vs. Skill Paths

| Job Role Paths | Skill Paths |
|---|---|
| Organize learning around the competencies required for a role. | Organize learning around a topic, toolset, or foundational skill. |
| Connect multiple technical domains into a practical workflow. | Develop or reinforce particular areas of technical knowledge. |
| Can support preparation for a role-oriented certification. | Can complement a job role curriculum with prerequisite or specialized knowledge. |

A Skill Path may support preparation for a Job Role Path, but the two categories remain separate in this repository so their scope and completion status can be tracked independently.
