## SOC Analyst

The SOC Analyst path focuses on practical security operations, including:

- Security monitoring and SIEM investigations
- Log analysis and threat detection
- Threat hunting and detection engineering
- Network traffic analysis
- Malware analysis and digital forensics
- Incident handling and reporting

See the [SOC Analyst path documentation](./soc-analyst/) for the module list and detailed progress.
