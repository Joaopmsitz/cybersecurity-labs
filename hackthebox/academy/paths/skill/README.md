## Path Summaries

### Basic Toolset

A practical collection of tools used in network and web application assessments, including Nmap, brute-force tools, Ffuf, Hashcat, SQLMap, traffic analysis tools, and web proxies.

**Main focus:** enumeration, authentication testing, web fuzzing, password cracking, SQL injection testing, traffic analysis, and proxy workflows.

[Open Basic Toolset documentation](./basic-toolset/README.md)

### Cracking into Hack the Box

A beginner-friendly path covering web requests, JavaScript deobfuscation, and the foundational knowledge needed to navigate HTB and approach hands-on challenges.

**Main focus:** HTTP fundamentals, client-side JavaScript analysis, platform orientation, and structured challenge-solving workflows.

[Open Cracking into Hack the Box documentation](./cracking-into-hack-the-box/README.md)

## Choosing a Path

- **Basic Toolset:** useful for learning commonly used technical assessment tools and understanding when to apply them.
- **Cracking into Hack the Box:** useful for building foundational web knowledge and becoming familiar with the HTB learning environment.

These paths cover different learning objectives. Their module lists and technical notes remain in their individual README files.

## Documentation Structure

Each path has its own directory and README containing its overview, module table, skills covered, completion information, and references.

Individual module documentation is linked from the relevant path README. When a module is shared across multiple paths, prefer linking to its existing technical documentation rather than duplicating the same material.
