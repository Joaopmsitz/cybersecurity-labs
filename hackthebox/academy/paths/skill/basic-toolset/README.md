## Description

This path covers a practical selection of tools commonly used during technical security assessments. The focus is on understanding the purpose of each tool, selecting the appropriate technique for the task, and interpreting the results.

The modules progress through network enumeration, authentication attacks, web application fuzzing, password recovery, SQL injection testing, network traffic analysis, and web proxy workflows.

## Skills Covered

- **Network enumeration:** host discovery, port scanning, service enumeration, and operating system detection with Nmap.
- **Authentication testing:** brute-force techniques, login workflows, and custom wordlists.
- **Web application fuzzing:** discovering directories, virtual hosts, and parameters with Ffuf.
- **Password cracking:** applying Hashcat with wordlists and different attack strategies.
- **SQL injection testing:** using SQLMap to test and investigate database injection vulnerabilities.
- **Network traffic analysis:** inspecting packets and communication patterns with Wireshark and Tcpdump.
- **Web proxies:** intercepting, inspecting, and modifying HTTP requests during web assessments.

## Key Takeaways

- Choose tools according to the objective and the available evidence.
- Understand the results instead of relying exclusively on automated output.
- Combine enumeration and traffic analysis to build a clearer picture of a target.
- Use password-testing and web-assessment tools only within authorized environments.
- Keep notes of commands, findings, and relevant evidence to make assessments reproducible.
