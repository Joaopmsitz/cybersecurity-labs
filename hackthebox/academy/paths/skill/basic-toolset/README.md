## Skills Covered

- **Network enumeration:** host discovery, port scanning, service enumeration, and operating system detection with Nmap.
- **Authentication testing:** brute-force techniques, service logins, and custom wordlists.
- **Web application fuzzing:** discovering directories, virtual hosts, and parameters with Ffuf.
- **Password cracking:** using Hashcat with wordlists, rules, and masks.
- **SQL injection testing:** using SQLMap to test injection vulnerabilities and interact with databases.
- **Network traffic analysis:** inspecting and analyzing network traffic with Wireshark and Tcpdump.
- **Web proxies:** working with web proxy tools during web application assessments.
