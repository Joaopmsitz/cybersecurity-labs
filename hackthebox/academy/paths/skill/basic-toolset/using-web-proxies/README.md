## Overview

Web proxies let security testers inspect and modify HTTP(S) requests and responses between a browser and a web application.

## Core Features

| Feature | Purpose |
|---|---|
| Intercept | Pause and inspect requests and responses |
| HTTP history | Review traffic generated by the browser |
| Repeater | Modify and resend an individual request |
| Scope | Limit attention to authorized target hosts |
| Proxy configuration | Route browser traffic through the testing proxy |
| HTTPS certificate | Enable inspection of TLS traffic in a controlled lab |

## Practical Workflow

1. Configure a dedicated browser profile to use the proxy.
2. Set the target scope before testing.
3. Browse the lab application and inspect HTTP history.
4. Send a relevant request to a replay tool such as Repeater.
5. Change one parameter at a time and compare responses.
6. Record evidence and restore any modified test data.

## Key Concepts

- HTTP methods, headers, cookies, and status codes
- Request and response bodies
- Session management
- URL encoding and parameter handling
- Comparing normal and modified responses
- Keeping tests within the configured scope

## Lab Notes

Record the request, the modification made, the resulting response, and what the result demonstrates.
