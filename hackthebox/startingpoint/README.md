# Hack The Box — Starting Point

Guided hands-on labs focused on cybersecurity fundamentals, service enumeration, exploitation, and basic privilege escalation.

## Tiers

| Tier | Focus | Directory |
| --- | --- | --- |
| Tier 0 | Foundational concepts, basic enumeration, and introductory service exploitation. | [Browse Tier 0](./tier-0/) |
| Tier 1 | More involved service enumeration, vulnerability analysis, and exploitation. | [Browse Tier 1](./tier-1/) |
| Tier 2 | Guided challenges involving broader attack paths and additional technical analysis. | [Browse Tier 2](./tier-2/) |

## Skills Practiced

- Network and service enumeration
- Web and service vulnerability analysis
- Authentication and credential analysis
- Exploitation fundamentals
- Linux and Windows basics
- Technical documentation and troubleshooting

## Documentation

Each tier directory contains its respective lab materials and notes. Individual write-ups should document the techniques used, relevant evidence, results, and lessons learned.

## Responsible Use

All practical testing is limited to authorized Hack The Box environments. Follow the platform's rules when documenting and publishing solutions.
