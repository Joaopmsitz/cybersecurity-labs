## What I Practiced

- Network enumeration with Nmap.
- Identification of the HTTP service on TCP port 80.
- Web application enumeration and login form analysis.
- Identification and exploitation of SQL injection.
- Authentication bypass by manipulating SQL query syntax.
- Retrieval of the flag after successfully bypassing authentication.
- Recognition of insecure database query construction.

## Key Takeaways

- SQL injection occurs when untrusted input is interpreted as part of a SQL query.
- Vulnerable login forms can allow authentication bypass without valid credentials.
- Parameterized queries and prepared statements help prevent SQL injection.
- Input validation alone is not a substitute for secure database query construction.
- Proper authentication controls are essential for protecting web applications.
