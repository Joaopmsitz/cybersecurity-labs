# LetsDefend — SOC Investigations

Collection of documented SOC investigation exercises completed on the LetsDefend platform, covering alert triage, evidence analysis, threat validation, and incident classification.

## Investigation Categories

| Category | Cases | Focus |
| --- | ---: | --- |
| [Brute Force](./brute-force/) | 1 | RDP brute-force and authentication analysis |
| [Malware](./malware/) | 4 | Malware alerts, suspicious files, scripts, and macros |
| [Phishing](./phishing/) | 7 | Phishing emails, malicious attachments, URLs, and delivery techniques |
| [Web Attacks](./web-attacks/) | 2 | SQL injection indicators and suspicious JavaScript in URLs |

## Investigation Approach

Each case documents the relevant evidence, analysis, findings, and conclusions supported by the training scenario.

The documentation aims to develop practical skills in:

- Alert triage and investigation
- Log and artifact analysis
- Indicator of Compromise (IOC) identification
- Threat validation and classification
- Incident reporting and documentation

## Scope

These are training exercises completed on LetsDefend. Findings and response actions refer to the documented scenarios and should not be interpreted as real-world incident response experience.
