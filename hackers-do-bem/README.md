## Tools and Technologies

The documented activities cover tools and technologies across several cybersecurity domains.

| Category | Tools and Technologies | Typical Context |
|---|---|---|
| Network Analysis | Wireshark, tcpdump, Nmap | Network traffic inspection, discovery, and analysis. |
| Web Security | Burp Suite | Web application security testing in authorized environments. |
| Cryptography and Certificates | OpenSSL | Cryptographic operations and digital certificate tasks. |
| Detection and Monitoring | Suricata, ClamAV | Network intrusion detection and malware scanning. |
| Automation and Scripting | Python, PowerShell | Scripting and automation exercises. |

| Network Security | iptables, OpenVPN | Packet filtering, firewall rules, and VPN-related activities. |

Refer to each activity's documentation for the tools actually used and the context in which they were applied. A tool listed here indicates documented study or lab practice, not necessarily professional experience.

## Documentation Standards

Where applicable, each activity includes:

- **Objective and technical context:** The purpose of the exercise and the concepts being investigated.
- **Lab environment and tools:** The systems, interfaces, and utilities used.
- **Procedures and commands:** The steps performed during the activity.
- **Observed results and technical interpretation:** Relevant outputs, findings, and explanations.
- **Cybersecurity concepts:** The main technologies and principles explored.
- **Supporting evidence:** Screenshots or other lab evidence where appropriate.

All published evidence should be reviewed to ensure that it contains no personal data, credentials, sensitive infrastructure details, or materials that the program does not authorize for public distribution.

## About the Program

Hackers do Bem is a Brazilian cybersecurity training initiative that provides learning opportunities across foundational and specialized cybersecurity topics. The program combines theoretical instruction with practical activities and aims to develop cybersecurity skills. For official program information, see the resources below.
