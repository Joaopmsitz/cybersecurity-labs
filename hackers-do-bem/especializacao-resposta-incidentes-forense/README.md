## Areas of Study

The specialization covers several complementary areas of cybersecurity operations:

### Security Monitoring and Threat Investigation

- Network Security Monitoring (NSM) and Enterprise Security Monitoring (ESM).
- Security event collection, analysis, and correlation.
- Network reconnaissance and traffic inspection.
- Detection engineering and threat hunting.
- Security Information and Event Management (SIEM).

### Incident Response

- Incident identification, triage, and classification.
- Investigation and evidence preservation.
- Containment, eradication, and recovery.
- Incident response playbooks and operational workflows.
- Post-incident analysis and lessons learned.

### Digital Forensics

- Examination of system and network artifacts.
- Log analysis and event reconstruction.
- File identification, extraction, and hashing.
- Malware-related evidence analysis.
- Documentation and preservation of investigation results.

### CSIRT Operations and Infrastructure

- CSIRT structure and responsibilities.
- Secure communication channels.
- Incident management and ticketing workflows.
- Network segmentation and infrastructure availability.
- Monitoring, redundancy, and business continuity.

## Documentation Approach

Each module and class is organized into its own directory.

Class-level documentation provides an overview of the practical activities, while individual activity READMEs describe the corresponding technical work.

Where applicable, documentation includes:

- Activity objectives and technical context.
- Tools, technologies, and lab environment.
- Procedures, commands, and configurations.
- Observed results and technical analysis.
- Relevant security concepts and learning outcomes.
- Links to supporting evidence.

Evidence files are organized at the class level whenever a single PDF is required for multiple activities.

## Learning Outcomes

The specialization develops practical understanding of:

- Security monitoring and incident detection.
- Network and endpoint investigation.
- SIEM queries, alerts, and dashboards.
- Network traffic analysis and forensic artifacts.
- Malware investigation and evidence handling.
- Incident response planning and execution.
- Detection rules and threat intelligence frameworks.
- CSIRT infrastructure, processes, and operational requirements.
- Technical documentation and continuous improvement.
