# Activity 6.1 - Preparing Splunk to Receive Zeek Logs

## Overview

This activity prepares Splunk to receive network monitoring data generated by Zeek. The first step is to verify the structure of Zeek connection logs and create a dedicated index in Splunk.

## Objectives

- Inspect Zeek connection logs.
- Verify that the logs are available in JSON format.
- Create the `zeek` index in Splunk Enterprise.

## Environment

| Component | Description |
|---|---|
| Network Monitor | Zeek |
| SIEM | Splunk Enterprise |
| Zeek Log Directory | `/opt/zeek/logs/current` |
| Main Log File | `conn.log` |

## Procedure

### 1. Inspect Zeek Connection Logs

```bash
less /opt/zeek/logs/current/conn.log
```

Inspect the records and verify that the log data is formatted as JSON.

### 2. Create the Splunk Index

In Splunk Enterprise:

1. Open **Settings**.
2. Navigate to **Data > Indexes**.
3. Select **New Index**.
4. Enter `zeek` as the index name.
5. Complete the index creation process.

## Expected Result

A dedicated Splunk index named `zeek` is available to receive Zeek network monitoring data.

## Technical Notes

- The index provides a dedicated destination for Zeek events.
- JSON formatting is important for the subsequent parsing and analysis workflows.
- This activity prepares the indexing destination; log forwarding is addressed in Activity 6.2.
