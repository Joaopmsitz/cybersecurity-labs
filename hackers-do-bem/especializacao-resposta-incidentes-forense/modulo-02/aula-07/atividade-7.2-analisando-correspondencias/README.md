# Activity 7.2 - Analyzing Intelligence Matches

## Overview

This activity examines the results generated by the Zeek Intelligence Framework. The `intel.log` file records positive matches between observed network data and the configured intelligence indicators.

## Objectives

- Inspect the generated `intel.log`.
- Confirm a positive IP indicator match.
- Understand the fields recorded by Zeek when an indicator is matched.

## Environment

| Component | Description |
|---|---|
| Virtual Machine | `forenseLinux` |
| Network Monitor | Zeek |
| Log File | `intel.log` |
| Offline Analysis Directory | `/opt/zeek/intel` |
| Live Log Directory | `/opt/zeek/logs/current` |

## Procedure

### 1. Open the Intelligence Log

For the offline exercise from Activity 7.1, open the generated log:

```bash
sudo nano /opt/zeek/intel/intel.log
```

For live monitoring, the current Zeek log directory may contain the intelligence log:

```bash
sudo nano /opt/zeek/logs/current/intel.log
```

Inspect the records and verify the positive match for the configured indicator.

### 2. Understand the Match Fields

| Field | Description |
|---|---|
| `seen.indicator` | Indicator that Zeek observed |
| `seen.indicator_type` | Type of the observed indicator |
| `seen.where` | Protocol event or location where the indicator was detected |
| `seen.node` | Zeek node that reported the match |
| `matched` | Indicator type that matched |
| `sources` | Intelligence source label associated with the indicator |

A match can be detected in different protocol contexts. For example, a domain indicator may appear in a DNS request, a TLS server name, or an X.509 certificate.

## Expected Result

The `intel.log` file contains a record indicating that the configured IP address was observed and matched against the intelligence data.

## Technical Notes

- The Intel Framework logs matches, not every network event.
- `seen.where` identifies the context in which an indicator was observed.
- `sources` corresponds to the intelligence source metadata configured in the indicator file.
- For offline processing, inspect the output directory used when Zeek processed the PCAP. For continuously monitored traffic, inspect the active Zeek log directory.
