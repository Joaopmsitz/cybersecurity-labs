# Hackers do Bem - Specialization | Module 02 - Class 07

This class covers threat intelligence integration, network threat hunting, and traffic analysis using Zeek and RITA. The practical activities demonstrate how intelligence indicators can be matched against network activity and how Zeek logs can be analyzed to identify suspicious communication patterns.

## Technical Notes

- Zeek intelligence files require tab-separated fields.
- The `frameworks/intel/seen` script enables reporting of observed data to the Intelligence Framework.
- Positive intelligence matches are recorded in `intel.log`.
- Offline Zeek processing writes output logs to the execution directory; live monitoring commonly writes logs under the current log directory.
- Threat intelligence indicators should be reviewed for relevance and freshness before operational use.
- RITA analyzes Zeek logs to identify communication patterns such as beaconing and long-lived connections.
- The course uses a legacy RITA 5 installer in its lab environment. Current RITA installation requirements may differ.
- The course's use of `--rolling` is retained in the lab procedure. Current RITA guidance reserves rolling datasets for recent network data, generally less than 24 hours old.
