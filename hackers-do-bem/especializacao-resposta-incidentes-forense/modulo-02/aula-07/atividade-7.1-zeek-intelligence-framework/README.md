# Activity 7.1 - Zeek Intelligence Framework

## Overview

This activity configures the Zeek Intelligence Framework to load IP indicators and identify matches in network traffic. A provided PCAP file is processed offline to generate Zeek logs, including `intel.log`.

## Objectives

- Enable the Zeek Intelligence Framework.
- Configure an intelligence file.
- Inspect a PCAP file for an external IP address.
- Process the PCAP offline with Zeek.
- Generate and inspect the resulting log files.

## Environment

| Component | Description |
|---|---|
| Virtual Machine | `forenseLinux` |
| Network Monitor | Zeek |
| PCAP Inspection | tcpick |
| Zeek Configuration | `/opt/zeek/share/zeek/site/local.zeek` |
| Intelligence Directory | `/opt/zeek/intel` |

## Procedure

### 1. Configure the Intelligence Framework

Edit the local Zeek configuration:

```bash
sudo nano /opt/zeek/share/zeek/site/local.zeek
```

Add the following configuration:

```zeek
# Enable the Zeek Intelligence Framework
@load frameworks/intel/seen
redef Intel::read_files += { "/opt/zeek/intel/zeek_intel.txt" };
```

Create the intelligence directory if it does not exist:

```bash
sudo mkdir -p /opt/zeek/intel
```

Apply the configuration:

```bash
sudo /opt/zeek/bin/zeekctl stop
sudo /opt/zeek/bin/zeekctl deploy
```

### 2. Inspect the PCAP File

Move to the intelligence directory:

```bash
cd /opt/zeek/intel
```

Inspect the TCP streams in the provided capture:

```bash
sudo /sbin/tcpick -C -yP -r 2021-02-08-traffic-analysis-exercise.pcap
```

The training exercise identifies `213.5.229.12` as the external IP indicator used for the test.

### 3. Create the Intelligence File

Create the file:

```bash
sudo nano /opt/zeek/intel/zeek_intel.txt
```

Use the following structure. Every field must be separated by a literal TAB character:

```text
#fieldsindicatorindicator_typemeta.source
213.5.229.12Intel::ADDRteste_1
```

The fields represent:

| Field | Value | Purpose |
|---|---|---|
| `indicator` | `213.5.229.12` | IP address to match |
| `indicator_type` | `Intel::ADDR` | Zeek indicator type |
| `meta.source` | `teste_1` | Source label for the indicator |

### 4. Process the PCAP Offline

Run Zeek from the intelligence directory:

```bash
cd /opt/zeek/intel
sudo /opt/zeek/bin/zeek -r /opt/zeek/intel/2021-02-08-traffic-analysis-exercise.pcap /opt/zeek/share/zeek/site/local.zeek
```

The `-r` option tells Zeek to analyze the specified PCAP file offline.

### 5. List the Generated Logs

Configure the terminal prompt as required by the course before capturing terminal evidence:

```bash
export PS1="$(echo "\d \t $PS1"|sed -e 's/\\\u/meunome/g')"
```

Replace `meunome` with the required alias.

List the generated files:

```bash
cd /opt/zeek/intel
ls -l
```

The generated logs depend on the protocols and activity present in the PCAP. The Intelligence Framework produces `intel.log` when a positive indicator match is detected.

## Expected Result

Zeek processes the provided PCAP and generates its log files. The expected intelligence match is recorded in `intel.log` when the configured indicator is observed.

## Technical Notes

- The Zeek Intelligence Framework loads indicator data from text files.
- `@load frameworks/intel/seen` enables observed data to be checked against the loaded indicators.
- `Intel::read_files` defines which intelligence files Zeek reads.
- The intelligence file must use literal TAB characters between fields.
- Offline output is written to the working directory from which Zeek is executed.
