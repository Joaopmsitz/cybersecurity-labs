## 1. Objective

Monitor Linux authentication events through Splunk Enterprise and investigate records generated by user creation and account modification.

The activity demonstrates how a SIEM platform can centralize system logs and make user-related activity easier to investigate.

## 5. Observed Events

The following event data was transcribed from the available screenshot.

### Event 1 — Root Session Closed

```text
2026-05-08T20:52:58.267993-03:00 ip-192-168-98-10 sudo: pam_unix(sudo:session): session closed for user root
```

Interpretation: The system recorded the closure of a sudo session associated with the root account.

### Event 2 — Group Membership Updated

```text
2026-05-08T20:52:58.257214-03:00 ip-192-168-98-10 gpasswd[5350]: members of group users set by root to exemplo
```

Interpretation: The root account modified group membership, setting the listed member to `exemplo`.

### Event 3 — User Information Changed

```text
2026-05-08T20:52:54.714179-03:00 ip-192-168-98-10 chfn[5097]: changed user 'exemplo' information
```

Interpretation: The account information for `exemplo` was modified using the account information utility.

### Event 4 — Keyring Warning

```text
2026-05-08T20:52:14.367741-03:00 ip-192-168-98-10 passwd[5063]: gkr-pam: couldn't update the login keyring password: no old password was entered
```

Interpretation: The authentication process reported that the login keyring password could not be updated because no previous password was supplied.

This message should be distinguished from the subsequent password-change record.

### Event 5 — Password Change Recorded

```text
2026-05-08T20:52:14.367594-03:00 ip-192-168-98-10 passwd[5063]: pam_unix(passwd:chauthtok): password changed for exemplo
```

Interpretation: The PAM authentication subsystem recorded a password change for `exemplo`.

### Event 6 — New User Created

```text
2026-05-08T20:52:09.352619-03:00 ip-192-168-98-10 useradd[5054]: new user: name exemplo, UID=1004, GID=1004, home /home/exemplo, shell /bin/bash, from /dev/pts/1
```

Interpretation: The user account was created with UID 1004, GID 1004, and the specified home directory and shell.

### Event 7 — New Group Created

```text
2026-05-08T20:52:09.301693-03:00 ip-192-168-98-10 groupadd[5048]: new group: name exemplo, GID=1004
```

Interpretation: A group named `exemplo` was created with GID 1004.

## 8. Technical Analysis

The event sequence demonstrates how a Linux account lifecycle can be traced through several system processes.

| Process | Investigative Context |
|---|---|
| groupadd | Group creation |
| useradd | User account creation |
| passwd | Password modification |
| chfn | User information modification |
| gpasswd | Group membership changes |
| sudo | Privileged session activity |

The combination of these records provides greater context than examining a single authentication event.

For example, the `useradd` event identifies the initial account creation, while subsequent records document additional account modifications.
