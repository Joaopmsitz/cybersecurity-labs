# Module 10 — System Security and Administration

This module covers practical activities involving Windows Server security, Linux security tools, virtualization, disk encryption, and container management.

## Activities — Classes 37–38

| Activity | Topic | Description | View |
|---|---|---|---|
| **10.01** — Memory Integrity and Maintenance | Windows Server 2022 | Explore Memory Integrity, Windows security settings, and system maintenance tools. | [View](aula-37-38/atividade-10.01-integridade-memoria-windows-server/) |
| **10.02** — App and Browser Control | Windows Server 2022 | Configure reputation-based protection, potentially unwanted app blocking, and Exploit Protection settings. | [View](aula-37-38/atividade-10.02-app-browser-control-windows-server/) |
| **10.03** — Exploring Windows Server Updates | Windows Server 2022 | Check for updates, review update settings, and inspect update history. | [View](aula-37-38/atividade-10.03-explorando-atualizacoes-windows-server/) |
| **10.04** — ClamAV on Kali Linux | Antivirus | Update antivirus signatures, scan files and directories, and review scan results using ClamAV. | [View](aula-37-38/atividade-10.04-clamav-kali-linux/) |
| **10.05** — Suricata on Kali Linux | Network Security | Configure Suricata, inspect detection rules, monitor network traffic, and review IDS logs and statistics. | [View](aula-37-38/atividade-10.05-suricata-kali-linux/) |

| Activity | Topic | Description | View |
