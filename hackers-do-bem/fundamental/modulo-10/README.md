# Hackers do Bem — Fundamental | Module 10

This module covers practical activities involving Windows Server security, Linux security tools, virtualization, disk encryption, and container management.

## Activities

### Activities — Class 37–38

| Activity | Topic | Description | View |
|---|---|---|---|
| 10.01 — Memory Integrity and Maintenance in Windows Server 2022 | File Integrity | Explore the Memory Integrity, Core Isolation, and Security and Maintenance features in Windows Server 2022, while also reviewing the reliability history and automatic maintenance capabilities of the system. | [View](./aula-37-38/atividade-10.01-integridade-memoria-manutencao-windows-server/README.md) |
| 10.02 — App and Browser Control in Windows Server 2022 | Cybersecurity Practice | Explore the App & browser control, Reputation-based protection, and Exploit Protection features in Windows Security on Windows Server 2022, reviewing the main security settings designed to protect against malicious applications and exploitation te... | [View](./aula-37-38/atividade-10.02-controle-aplicativos-navegadores-windows-server/README.md) |
| 10.03 — Exploring Windows Server 2022 Updates | Cybersecurity Practice | Explore the Windows Server 2022 update environment by checking for available updates, updating the system, and reviewing advanced update settings and notification options. | [View](./aula-37-38/atividade-10.03-atualizacoes-windows-server/README.md) |
| 10.04 — ClamAV on Kali Linux | Cybersecurity Practice | Install, update, and use ClamAV on Kali Linux to scan files, while also examining the engine version, signature database updates, and antivirus configuration information. | [View](./aula-37-38/atividade-10.04-clamav-kali/README.md) |
| 10.05 — Suricata on Kali Linux | Cybersecurity Practice | Configure and run Suricata on Kali Linux, using detection rules to monitor network traffic and examining the log files generated by the engine. | [View](./aula-37-38/atividade-10.05-suricata-kali/README.md) |
