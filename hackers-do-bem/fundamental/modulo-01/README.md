# Hackers do Bem — Fundamental | Module 01

## Skills Practiced

- File integrity verification and change detection
- Binary comparison and cryptographic hashing
- Classical encryption and decryption concepts
- Linux command-line operations and task management
- Phishing awareness and controlled security simulation
- WHOIS queries and passive reconnaissance
- OSINT data collection and correlation
- Maltego transforms and relationship visualization
- Adversarial examples and machine learning model robustness
- Technical documentation and evidence handling

## Documentation Standards

Each activity README documents the objective, environment, procedure, commands or tools used, observed results, relevant concepts, and supporting evidence where applicable.

Evidence files are organized by class group. Published materials should be reviewed to avoid exposing real credentials, personal information, or data that is not authorized for public distribution.
