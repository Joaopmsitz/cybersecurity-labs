# Hackers do Bem — Fundamental | Module 01

Index of practical activities documented for Module 01 of the Hackers do Bem Fundamental training stage.

The activities cover file integrity, hashing, classical cryptography, task management, phishing simulations, WHOIS, OSINT, and adversarial machine learning.

## Activities

### Activities — Class 01–02

| Activity | Topic | Description | View |
|---|---|---|---|
| 1.1 — Comparing Text Files to Detect Changes | File Integrity | Verify whether a text file has changed by comparing an original file with a copy. This activity uses the Linux diff command to identify differences after modifying the copied file. | [View](./aula-01-02/atividade-1.1-integridade-texto/README.md) |
| 1.2 — Comparing Binary File Integrity | File Integrity | Verify the integrity of binary files by comparing identical and modified files. This activity uses image files as examples and the Linux cmp command to detect byte-level differences. | [View](./aula-01-02/atividade-1.2-integridade-arquivos/README.md) |
| 1.3 — Verifying File Integrity with MD5 Hashes | Cryptographic Hashing | Verify file integrity by calculating and comparing MD5 hashes for identical and modified files. | [View](./aula-01-02/atividade-1.3-hash/README.md) |
| 1.4 — Classical Cryptography with ROT13 and Caesar Cipher | Cryptography | Explore basic cryptography concepts by applying the ROT13 substitution cipher and implementing a Caesar cipher in Python. | [View](./aula-01-02/atividade-1.4-criptografia/README.md) |
| 1.5 — Task Management with Taskwarrior | Linux Administration | Practice command-line task management using Taskwarrior by creating tasks, adding tags, setting due dates, and marking tasks as completed. | [View](./aula-01-02/atividade-1.5-taskwarrior/README.md) |

### Activities — Class 03–04

| Activity | Topic | Description | View |
|---|---|---|---|
| 1.6 — Exploring ShellPhish on Kali Linux | Social Engineering | Explore the basic operation of a phishing simulation tool in a controlled laboratory environment. | [View](./aula-03-04/atividade-1.6-phishing/README.md) |
| 1.7 — Exploring WHOIS on Kali Linux | Domain Intelligence | Use the whois tool to retrieve publicly available domain registration information and examine details such as the responsible organization, technical contact identifiers, and DNS name servers. | [View](./aula-03-04/atividade-1.7-whois/README.md) |
| 1.8 — Exploring Maltego on Kali Linux | Open-Source Intelligence | Become familiar with Maltego and its use in Open-Source Intelligence (OSINT) and public-information reconnaissance. | [View](./aula-03-04/atividade-1.8-maltego/README.md) |
| 1.9 — Conducting OSINT with Maltego | Open-Source Intelligence | Use Maltego to conduct an Open-Source Intelligence (OSINT) investigation, starting with a public domain and applying different Transforms to identify related infrastructure, DNS information, people, email addresses, and mail servers. | [View](./aula-03-04/atividade-1.9-osint/README.md) |
| 1.10 — Adversarial Machine Learning | Artificial Intelligence Security | Demonstrate the concept of Adversarial Machine Learning using an interactive image recognition application. | [View](./aula-03-04/atividade-10-adversarial-ml/README.md) |
