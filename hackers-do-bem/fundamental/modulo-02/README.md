# Fundamental — Module 02

> **Program:** Hackers do Bem  
> **Stage:** Fundamental  
> **Module:** 02  
> **Status:** Completed activities documented below

## Overview

This module covers practical activities related to security tools, malware-related artifacts, Linux log monitoring, privacy technologies, and Windows security configuration.

The exercises include controlled security-tool demonstrations, file encryption, log analysis, Tor Browser usage, Onion Services, and Local Security Policy in Windows Server 2022.

All activities are documented individually, with supporting evidence organized by class group.

## Skills and Concepts Covered

- Security tools and controlled payload demonstrations
- Keylogger behavior and endpoint protection mechanisms
- Malware-related artifacts and security precautions
- File encryption and decryption
- Linux system log monitoring and event interpretation
- Tor Browser, Tor exit nodes, and public IP address visibility
- Onion Services and `.onion` address concepts
- Windows Server 2022 Local Security Policy
- Password and account lockout policies
- Security auditing and user rights assignment
- Security configuration and least privilege

## Documentation and Evidence

Each activity has its own README containing the objective, environment, procedure, relevant observations, and results. Evidence is grouped into PDF files for the corresponding class sessions.

The terminal outputs and observations documented in the individual activity files represent the results recorded during the laboratory exercises. They should not be interpreted as current system states or as guarantees about the behavior of tools and services outside the original environment.
