# Hackers do Bem — Fundamental | Module 02

> Program: Hackers do Bem > Stage: Fundamental > Module: 02 > Status: Completed activities documented below

## Activities

### Activities — Class 05–06

| Activity | Topic | Description | View |
|---|---|---|---|
| 2.01 — Creating and Analyzing a Windows Remote-Access Payload with SET | Cybersecurity Practice | Explore the Social-Engineer Toolkit (SET) in a controlled laboratory environment to understand the generation of a Windows remote-access payload and observe how the resulting file is evaluated by a malware analysis platform. | [View](./aula-05-06/atividade-2.01-trojan-acesso-remoto/README.md) |
| 2.02 — Exploring the XSPY Keylogger on Kali Linux | Cybersecurity Practice | Explore the basic operation of the XSPY keylogger in a controlled laboratory environment. | [View](./aula-05-06/atividade-2.02-keylogger-xspy/README.md) |
| 2.03 — Exploring Ransomware Artifacts on Kali Linux | Cybersecurity Practice | Explore a ransomware artifact-generation tool in a controlled laboratory environment, review the available ransomware family labels, generate an artifact, and inspect the resulting file in the Linux filesystem. | [View](./aula-05-06/atividade-2.03-ransomware/README.md) |
| 2.04 — Exploring Multiple Malware Payloads with Brutal | Malware Analysis | Explore the Brutal toolkit in a controlled laboratory environment to understand its structure, review the available payload categories, and generate an artifact associated with a screen-rotation prank. | [View](./aula-05-06/atividade-2.04-multiplos-payloads-malware/README.md) |
| 2.05 — Observing Microsoft Defender SmartScreen Protection Against a Keylogger Sample | Cybersecurity Practice | Explore how Windows security protections respond to a file associated with a keylogger in a controlled laboratory environment. | [View](./aula-05-06/atividade-2.05-windows-defender-keylogger/README.md) |

### Activities — Class 07–08

| Activity | Topic | Description | View |
|---|---|---|---|
| 2.06 — Exploring File Encryption with Ccrypt on Kali Linux | Cryptography | Explore the Ccrypt command-line utility on Kali Linux to understand the process of encrypting and decrypting a file. | [View](./aula-07-08/atividade-2.06-ccrypt/README.md) |
| 2.07 — Analyzing Linux System Events with Logcheck | Cybersecurity Practice | Use Logcheck to analyze events recorded by a Linux system, focusing on authentication activity, network services, and error messages. | [View](./aula-07-08/atividade-2.07-logcheck/README.md) |
| 2.08 — Exploring Tor Browser on Kali Linux | Cybersecurity Practice | Configure and use Tor Browser on Kali Linux to observe how a connection through the Tor network can present a different public IP address from a conventional browser connection. | [View](./aula-07-08/atividade-2.08-tor-browser/README.md) |
| 2.09 — Exploring the Deep Web Through Tor Browser | Cybersecurity Practice | Use Tor Browser in a controlled educational environment to understand access to services available on the Tor network, examine the structure of .onion addresses, and distinguish the conventional Web from services accessible through the Tor network. | [View](./aula-07-08/atividade-2.09-deepweb-tor/README.md) |
| 2.10 — Exploring Local Security Policies in Windows Server 2022 | Purpose | Explore the Local Security Policy settings in Windows Server 2022, identifying configurations related to account management, passwords, account lockout, auditing, user rights assignment, and security options. | [View](./aula-07-08/atividade-2.10-politicas-seguranca-windows/README.md) |
