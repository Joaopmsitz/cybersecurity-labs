# Hackers do Bem — Fundamental | Module 09

> Program: Hackers do Bem > Stage: Fundamental > Module: 09 > Status: Completed

## Activities

### Activities — Class 33–34

| Activity | Topic | Description | View |
|---|---|---|---|
| 9.01 — Creating a Certificate Authority on Windows Server 2022 | Public Key Infrastructure | Implement a Certificate Authority (CA) using Windows Server 2022 and the Active Directory Certificate Services (AD CS) role. | [View](./aula-33-34/atividade-9.01-criando-autoridade-certificadora/README.md) |
| 9.02 — Issuing Digital Certificates Using a Certificate Authority | aluno.hacker.com | Use the Certificate Authority created in the previous activity to configure a certificate template, make it available on the CA, and configure auto-enrollment through a Group Policy Object (GPO). | [View](./aula-33-34/atividade-9.02-emitindo-certificados/README.md) |
| 9.03 — Examining the Digital Certificate Obtained on Windows Server 2022 | aluno.hacker.com | Access and analyze a digital certificate issued by the Certificate Authority configured in the previous activities. | [View](./aula-33-34/atividade-9.03-conhecendo-certificado-digital/README.md) |
| 9.04 — Evaluating Web Certificates on Windows Server 2022 | Public Key Infrastructure | Analyze a digital certificate used by a website and examine its main security and identification properties. | [View](./aula-33-34/atividade-9.04-avaliando-certificados-web/README.md) |
| 9.05 — Creating Self-Signed Digital Certificates on Kali Linux | Public Key Infrastructure | Create a self-signed digital certificate on Kali Linux using OpenSSL by generating an RSA private key, creating a Certificate Signing Request (CSR), and issuing the certificate. | [View](./aula-33-34/atividade-9.05-certificado-autoassinado-kali/README.md) |

### Activities — Class 35–36

| Activity | Topic | Description | View |
|---|---|---|---|
| 9.06 — Revoking a Certificate on Windows Server 2022 | Public Key Infrastructure | Revoke a digital certificate previously issued by the Windows Server 2022 Certificate Authority using the Certification Authority console. | [View](./aula-35-36/atividade-9.06-revogando-certificado-windows-server/README.md) |
| 9.07 — Unrevoking a Certificate on Windows Server 2022 | Public Key Infrastructure | Cancel the revocation of a previously revoked certificate in the Windows Server 2022 Certificate Authority, returning the certificate to the list of issued certificates. | [View](./aula-35-36/atividade-9.07-cancelar-revogacao-windows-server/README.md) |

| 9.10 — Recovering a Bitcoin Wallet and Generating a QR Code in Electrum | Cybersecurity Practice | Simulate the loss of a Bitcoin wallet in Electrum, recover it using its seed phrase, and generate a payment request using a Bitcoin address and QR code. | [View](./aula-35-36/atividade-9.10-recuperando-carteira-bitcoin-electrum/README.md) |
