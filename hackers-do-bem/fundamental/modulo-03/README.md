> **Program:** Hackers do Bem  
> **Stage:** Fundamental  
> **Module:** 03  
> **Status:** Activities documented below

## Overview

This module covers practical cybersecurity activities focused on vulnerability research, network scanning, HTTP traffic inspection, TCP connections, network diagnostics, honeypots, and DNS enumeration.

The exercises use tools available in Kali Linux to explore network services, analyze traffic, inspect DNS records, and understand techniques used in security assessment and reconnaissance.

The module contains **10 activities**, organized into two class groups, with supporting evidence stored in the corresponding class directories.

## Skills and Concepts Covered

- Vulnerability research using ExploitDB and SearchSploit.
- Host discovery and port scanning with Nmap.
- HTTP/HTTPS request interception and inspection with Burp Suite.
- TCP listeners and network communication using Netcat and Ncat.
- Network interface and connectivity diagnostics.
- Routing tables and protocol statistics.
- Honeypot configuration and network-event observation.
- HTTP request and header analysis.
- DNS record enumeration using `host`, NSLookup, and DIG.
- Analysis of A, AAAA, NS, MX, CNAME, SOA, and TXT records.
- Interpretation of DNS responses, TTL values, and mail-server preferences.
- Security reconnaissance within controlled laboratory environments.
