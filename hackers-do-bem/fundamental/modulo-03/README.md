# Hackers do Bem — Fundamental | Module 03

> Program: Hackers do Bem > Stage: Fundamental > Module: 03 > Status: Activities documented below

## Activities

### Activities — Class 09–10

| Activity | Topic | Description | View |
|---|---|---|---|
| 3.01 — Exploring Known Exploits with ExploitDB on Kali Linux | Cybersecurity Practice | Explore the Exploit Database (ExploitDB) using searchsploit, the search tool available in Kali Linux. | [View](./aula-09-10/atividade-3.01-exploitdb/README.md) |
| 3.02 — Network Scanning with Nmap | Network Programming and Reconnaissance | Use Nmap to discover hosts, identify active devices on a network, analyze port states, filter scan results, and observe the packets used during scanning. | [View](./aula-09-10/atividade-3.02-nmap/README.md) |
| 3.03 — Configuring and Using Burp Suite | Cybersecurity Practice | Configure Burp Suite as a local proxy to intercept and analyze HTTP/HTTPS requests generated by a browser in a controlled laboratory environment. | [View](./aula-09-10/atividade-3.03-burp-suite/README.md) |
| 3.04 — Creating a TCP Listener with Netcat | Cybersecurity Practice | Use Netcat (nc) to create a TCP listener on a specific port and observe an HTTP request sent by a web browser. | [View](./aula-09-10/atividade-3.04-netcat-listener/README.md) |
| 3.05 — Port Forwarding Concepts with Ncat | Cybersecurity Practice | Use Ncat, a networking utility included in the Nmap project, to observe how data can be passed between TCP connections using different ports. | [View](./aula-09-10/atividade-3.05-ncat-redirecionamento-portas/README.md) |

### Activities — Class 11–12

| Activity | Topic | Description | View |
|---|---|---|---|
| 3.06 — Exploring Network Diagnostic Tools on Kali Linux | Cybersecurity Practice | Use commands available in Kali Linux to diagnose network status, identify interfaces, test connectivity, inspect routes, query protocol statistics, and check active network connections and services. | [View](./aula-11-12/atividade-3.06-diagnostico-rede/README.md) |
| 3.07 — Creating a Honeypot with PentBox on Kali Linux | Cybersecurity Practice | Configure a honeypot using PentBox on Kali Linux and perform a controlled access test from a Windows Server 2022 machine. | [View](./aula-11-12/atividade-3.07-honeypot-pentbox/README.md) |
| 3.08 — DNS Enumeration with host on Kali Linux | Cybersecurity Practice | Use the host utility on Kali Linux to perform DNS queries and identify different types of records associated with domain names, including IPv4 addresses, IPv6 addresses, name servers (NS), and mail servers (MX). | [View](./aula-11-12/atividade-3.08-enumeracao-dns-host/README.md) |
| 3.09 — DNS Enumeration with NSLookup | Cybersecurity Practice | Use NSLookup to perform DNS queries and identify different types of records associated with a domain, including IP addresses, DNS servers, mail servers, and TXT records. | [View](./aula-11-12/atividade-3.09-enumeracao-dns-nslookup/README.md) |
| 3.10 — DNS Enumeration with DIG | Cybersecurity Practice | Use DIG (Domain Information Groper) to perform DNS queries and analyze different types of records associated with a domain. | [View](./aula-11-12/atividade-3.10-enumeracao-dns-dig/README.md) |
