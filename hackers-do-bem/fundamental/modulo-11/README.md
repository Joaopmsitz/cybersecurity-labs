# Module 11 — Network Configuration and Security

This module covers practical networking and security activities involving ARP, network interface configuration, MAC address cloning, Quality of Service (QoS), firewall rules, DNS redirection, VPN connectivity, and ICMP filtering using Kali Linux and Windows Server 2022.

## Activities — Classes 41–42

| Activity | Topic | Description | View |
|---|---|---|---|
| 11.01 — ARP Table on Kali Linux | Network Administration | Inspect the ARP table and examine IP-to-MAC address mappings on Kali Linux. | [View](./aula-41-42/atividade-11.01-tabela-arp-kali/README.md) |
| 11.02 — Network Interface Aliases on Kali Linux | Network Configuration | Configure and explore network interface aliases in Kali Linux. | [View](./aula-41-42/atividade-11.02-alias-interface-rede-kali/README.md) |
| 11.03 — MAC Address Cloning on Kali Linux | Network Configuration | Explore MAC address cloning and network interface address configuration. | [View](./aula-41-42/atividade-11.03-mac-cloning-kali/README.md) |
| 11.04 — QoS on Kali Linux | Quality of Service | Explore Quality of Service concepts and traffic management in Kali Linux. | [View](./aula-41-42/atividade-11.04-qos-kali/README.md) |
| 11.05 — QoS on Windows Server | Quality of Service | Explore Quality of Service configuration and traffic management on Windows Server. | [View](./aula-41-42/atividade-11.05-qos-windows-server/README.md) |
