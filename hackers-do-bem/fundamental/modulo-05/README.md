## Module Overview

This module explores access control, Active Directory administration, domain authentication, Group Policy Objects (GPOs), Windows file permissions, Linux access control models, and password aging policies.

The ten activities are organized into two class groups and cover both Windows Server and Kali Linux laboratory environments.

## Skills and Concepts Covered

- Active Directory Domain Services (AD DS) installation and configuration
- Domain Controller deployment and forest creation
- DNS forward and reverse lookup zones
- Domain user and Organizational Unit management
- Windows domain client configuration and authentication
- Group Policy Objects and password policy configuration
- Remote Desktop authorization and user rights
- Discretionary Access Control (DAC) and NTFS permissions
- Linux file ownership, groups, and permission management
- Role-based access control concepts
- Linux password aging and account policy configuration

## Learning Outcomes

Through these activities, learners practiced deploying an Active Directory environment, creating domain users and organizational units, joining a Windows client to a domain, and applying administrative policies through GPOs.

The activities also demonstrated how Windows and Linux manage access to files and resources through permissions, groups, and account policies. The Linux exercises used traditional groups and file permissions to illustrate access control concepts, including DAC and role-based access.

All exercises were performed in controlled laboratory environments. Passwords, credentials, and other sensitive information should not be included in public repository documentation.
