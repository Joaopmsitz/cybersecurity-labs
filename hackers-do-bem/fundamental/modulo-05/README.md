### Activities — Class 17–18

| Activity | Topic | Description | View |
|---|---|---|---|
| 5.01 — Installing Active Directory on Windows Server 2022 | Directory Services Security | Install and prepare Active Directory Domain Services (AD DS) on Windows Server 2022, configuring the server that will subsequently be promoted to a Domain Controller. | [View](./aula-17-18/atividade-5.01-active-directory/README.md) |

| 5.03 — Creating a Domain User in Active Directory | aluno.hacker.com | Create a user in the Active Directory domain, add the user to the Remote Desktop Users group, and create a Group Policy Object (GPO) to allow domain users to log on through Remote Desktop Services. | [View](./aula-17-18/atividade-5.03-usuario-ad/README.md) |
| 5.04 — Configuring a Windows Server 2022 Domain Client | aluno.hacker.com | Configure a second Windows Server 2022 instance as an Active Directory domain client, using DC01 as its DNS server and Domain Controller. | [View](./aula-17-18/atividade-5.04-cliente-dominio/README.md) |
| 5.05 — Configuring a Password Policy GPO in Windows Server 2022 | aluno.hacker.com | Create and configure a Group Policy Object (GPO) to establish a password policy for the Active Directory domain. | [View](./aula-17-18/atividade-5.05-politica-senhas-gpo/README.md) |
