## Objective

This activity involved developing a Python script to automate the collection of Linux system information and generate a report containing the retrieved data.

The script collects information such as the hostname, kernel version, processor model, available memory, and storage usage, organizing this data into a text file.

The activity demonstrates how automation can be used to perform system inventory and information-gathering tasks.

### 2. Create the Python Script

The Mousepad text editor was used to create the following file:

```text
/home/aluno/Documentos/dados_linux.py
```

The script developed was:

```python
import os
import socket

# Function to collect system information
def coletar_informacoes_sistema():
    hostname = socket.gethostname()
    kernel_version = os.uname().release
    cpu_info = os.popen('cat /proc/cpuinfo | grep "model name" | uniq').read().strip()
    mem_info = os.popen('free -h | grep "Mem.:"').read().strip()
    disk_space = os.popen('df -h').read()

    informacoes = {
        "Hostname": hostname,
        "Kernel Version": kernel_version,
        "CPU Info": cpu_info,
        "Memory Info": mem_info,
        "Disk Space": disk_space
    }

    return informacoes

# Function to generate a report
def gerar_relatorio(informacoes):
    relatorio = "Linux System Report\n\n"
    for chave, valor in informacoes.items():
        relatorio += f"{chave}: {valor}\n"

    with open("relatorio_linux.txt", "w") as arquivo:
        arquivo.write(relatorio)

if __name__ == "__main__":
    informacoes_sistema = coletar_informacoes_sistema()
    gerar_relatorio(informacoes_sistema)
    print("Report successfully generated at 'relatorio_linux.txt'")
```

The script uses Python modules and operating system commands to collect system information and save it in a report.

### Kernel

### Memory

### Storage

The output from `df -h` provides information about the file systems, including:

- File system
- Total size
- Used space
- Available space
- Usage percentage
- Mount point

One important finding in the laboratory was:

```text
/dev/nvme0n1p1    20G   19G  101M 100% /
```

This indicates that the root partition was nearly out of available space, with utilization reported at 100%.

In a real environment, this condition requires attention because insufficient disk space can affect file writes, logging, updates, and service operation.

## Concepts Practiced

Automation transforms a sequence of manual tasks into a process that can be executed by a program.

In this laboratory, instead of manually running multiple commands to inspect the system, Python brought those operations together in a single script.

### Information Gathering

The script performs a basic system inventory, collecting:

- Hostname
- Kernel version
- CPU information
- Memory information
- Storage information

This type of collection can support system administration, troubleshooting, inventory, and monitoring activities.

The activity also demonstrates how a Python program can interact with information provided by the operating system.

For example:

os.popen('df -h').read()

executes the `df -h` command and captures its output for use in the program.
