# Hackers do Bem — Fundamental | Module 06

## Activities

### Activities — Class 21–22

| Activity | Topic | Description | View |
|---|---|---|---|
| 6.01 — Code Reuse in Python on Kali Linux | Network Programming and Reconnaissance | This activity demonstrates the concept of code reuse in Python using the Pillow library to process an image. | [View](./aula-21-22/atividade-6.01-reuso-codigo-python/README.md) |
| 6.02 — Exploring the Java Development Kit (JDK) and an IDE on Kali Linux | Cybersecurity Practice | This activity covers the installation and verification of the Java development environment on Kali Linux using the Java Development Kit (JDK) and Apache NetBeans as the IDE. | [View](./aula-21-22/atividade-6.02-jdk-netbeans/README.md) |
| 6.03 — Task Automation with Python on Kali Linux | Network Programming and Reconnaissance | This activity involved developing a Python script to automate the collection of Linux system information and generate a report containing the retrieved data. | [View](./aula-21-22/atividade-6.03-automacao-python/README.md) |
| 6.04 — Exploring ClamAV and Its Malware Signatures on Kali Linux | Malware Analysis | This activity introduces ClamAV, an open-source antivirus engine used on Linux systems, focusing on the clambc and sigtool utilities. | [View](./aula-21-22/atividade-6.04-clamav-assinaturas/README.md) |
| 6.05 — Task Automation with PowerShell on Windows Server | Cybersecurity Practice | This activity uses PowerShell to automate administrative tasks and information collection in a Windows Server environment. | [View](./aula-21-22/atividade-6.05-powershell/README.md) |

### Activities — Class 23–24

| Activity | Topic | Description | View |
|---|---|---|---|
| 6.06 — Exploring HTTP Requests and Percent-Encoding on Kali Linux | Cybersecurity Practice | This activity explores HTTP requests using the curl command on Kali Linux, including retrieving web page content, downloading files, and using Percent-Encoding in URL parameters. | [View](./aula-23-24/atividade-6.06-http-curl/README.md) |
| 6.07 — Shortening URLs and Generating QR Codes on Kali Linux | Cybersecurity Practice | This activity uses Kali Linux to perform two tasks related to URL management and sharing: | [View](./aula-23-24/atividade-6.07-encurtador-qr-code/README.md) |
