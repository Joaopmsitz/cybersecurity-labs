## Module Overview

This module covers Python and PowerShell automation, Java development tools, antivirus signatures, HTTP requests, URL encoding, QR code generation, clickjacking, and SQL Injection.

The ten activities are organized into two class groups and combine programming fundamentals, system administration, web technologies, and application security testing in controlled laboratory environments.

## Skills and Concepts Covered

- Python programming and code reuse
- Image processing with the Pillow library
- Java development tools and Apache NetBeans
- System inventory and automation with Python
- ClamAV utilities, bytecode signatures, and CVE references
- Windows system administration with PowerShell
- System information collection and Windows event log analysis
- HTTP requests and response inspection with `curl`
- URL parameters and Percent-Encoding
- URL shortening and QR code generation
- Clickjacking concepts and iframe behavior
- HTTP anti-framing protections using `X-Frame-Options` and CSP `frame-ancestors`
- SQL Injection identification and controlled testing with SQLmap
- Database enumeration and security assessment
- Application security risks and mitigation strategies

## Learning Outcomes

Through these activities, learners practiced reusing existing software libraries, automating system information collection, working with Java development tools, and interpreting antivirus signature information.

The module also introduced web request inspection, URL encoding, QR code generation, and clickjacking protection mechanisms. The SQL Injection exercise demonstrated how an insecure web application parameter can expose database structures and sensitive data in a designated testing environment.

All security testing activities were conducted in laboratory or training environments. Credentials, secrets, and other sensitive information should not be published in public repository documentation.
