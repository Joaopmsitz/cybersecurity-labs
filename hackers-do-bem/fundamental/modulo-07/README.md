# Hackers do Bem — Fundamental | Module 07

> Program: Hackers do Bem > Stage: Fundamental > Module: 07 > Status: Completed

## Activities

### Activities — Class 25–26

| Activity | Topic | Description | View |
|---|---|---|---|
| 7.01 — Implementing Software RAID 0 on Kali Linux | Cybersecurity Practice | Implement a software RAID 0 array on Kali Linux using two 100 MiB partitions created on a secondary disk attached to the virtual machine. | [View](./aula-25-26/atividade-7.01-raid-0-kali/README.md) |
| 7.02 — Implementing Software RAID 1 on Kali Linux | Cybersecurity Practice | Implement a Software RAID 1 array on Kali Linux using two new 100 MiB partitions on the secondary disk /dev/nvme1n1. | [View](./aula-25-26/atividade-7.02-raid-1-kali/README.md) |
| 7.03 — Manual Rsync | Cybersecurity Practice | Perform a manual file copy between two directories using rsync, understand the command's main parameters, and verify the integrity of the copied file. | [View](./aula-25-26/atividade-7.03-rsync-manual/README.md) |
| 7.04 — Automated Rsync with Cron | Cybersecurity Practice | Automate synchronization between two directories using rsync and cron. The goal is to configure a script that runs the copy operation automatically every minute, allowing files added to PastaA to be synchronized to PastaB. | [View](./aula-25-26/atividade-7.04-rsync-cron/README.md) |
| 7.05 — OneDrive Backup and Synchronization | Data Protection | Configure OneDrive on a Windows Server 2022 client to back up and synchronize system folders with cloud storage. | [View](./aula-25-26/atividade-7.05-onedrive-backup/README.md) |

### Activities — Class 27–28

| Activity | Topic | Description | View |
|---|---|---|---|
| 7.06 — Local Full Backup with Duplicity | Data Protection | Perform a local full backup using Duplicity on Kali Linux and then restore the files to verify the integrity of the backup. | [View](./aula-27-28/atividade-7.06-duplicity-backup-completo/README.md) |
| 7.07 — Local Differential Backup with Duplicity | File Integrity | Perform a local backup using Duplicity, building on the full backup created in the previous activity. | [View](./aula-27-28/atividade-7.07-duplicity-backup-diferencial/README.md) |
| 7.08 — Complete Formatting on Kali Linux | Cybersecurity Practice | Prepare and format a partition on Kali Linux by removing the previous RAID configuration, recreating the filesystem, and finally removing filesystem signatures using wipefs. | [View](./aula-27-28/atividade-7.08-formatacao-completa/README.md) |
| 7.09 — Simple Overwrite on Kali Linux | Cybersecurity Practice | Perform a simple overwrite on a partition in Kali Linux using random data, writing to the device until no space is available. | [View](./aula-27-28/atividade-7.09-sobrescrita-simples/README.md) |
| 7.10 — Overwriting with the DoD 5220.22-M Pattern | Cybersecurity Practice | Overwrite data on a partition using the shred command, applying one pass of random data followed by a pass of zeros. | [View](./aula-27-28/atividade-7.10-sobrescrita-dod/README.md) |
