# Activity 7.07 — Local Differential Backup with Duplicity

> **Program:** Hackers do Bem  
> **Stage:** Fundamental — Module 07  
> **Classes:** 27–28  
> **Environment:** Kali Linux  
> **Status:** Completed

## Objective

Perform a local backup using Duplicity, building on the full backup created in the previous activity.

In this activity, the contents of `teste.txt` are modified, and a new file is created. Duplicity is then run again against the same destination to record changes since the previous full backup.

## Environment

- **Operating system:** Kali Linux
- **Tool:** Duplicity
- **Source directory:** `/home/aluno/Documentos/Conteudo`
- **Backup destination:** `/home/aluno/Documentos/ArmazenaBackup`
- **Restore directory:** `/home/aluno/Documentos/BackupRestaurado2`

> Credentials used in the lab environment are not recorded in this README.

### Interpreting the Output

Duplicity identified changes since the previous full backup.

The following field was reported:

```text
SourceFiles 3
```

This indicates that three source files were considered during the backup operation.

The fields:

```text
ChangedFiles 1
ChangedFileSize 18 (18 bytes)
```

indicate that an existing file was modified. In this case, the file was `teste.txt`, whose content was changed to `Teste Diferencial`.

The output also reported new files:

```text
NewFiles 2
NewFileSize 4103 (4.01 KB)
```

Duplicity used the previous full backup as a reference and recorded changes in the `ArmazenaBackup` destination.

The process completed without errors:

```text
Errors 0
```


## 7. Concept Applied

A differential backup records changes made since the last full backup.

In this lab:

```text
Full backup
       ↓
teste.txt = "Teste"
       ↓
Changes
       ├── teste.txt → "Teste Diferencial"
       └── Create teste2.txt
       ↓
New backup
       ↓
Restoration
       ↓
teste.txt + teste2.txt
```

The main difference from a full backup is that the subsequent process uses the full backup as its baseline and records changes made since that backup.
