# Activity 8.02 — Obfuscating Python Code on Kali Linux

> **Program:** Hackers do Bem  
> **Stage:** Fundamental — Module 08  
> **Classes:** 29–30  
> **Environment:** Kali Linux  
> **Status:** Completed

## Objective

Use the Python compiler to generate an **optimized bytecode** version of a program and examine its behavior after changing the extension of the compiled file.

This activity demonstrates a basic way to make direct reading of the source code more difficult by transforming a Python program into bytecode. The resulting file does not retain the original source code's readable structure.

## Environment

- **Operating system:** Kali Linux
- **Language:** Python
- **Working directory:** `/home/aluno/Documentos/Arquivos`
- **Original file:** `arquivo.py`
- **Compiled file:** `arquivo.cpython-313.opt-2.pyc`
- **File used for execution:** `arquivo_ofuscado.py`

> Credentials used in the lab environment are not recorded in this README.

## 1. Switching to the Root User

Administrative access to Kali Linux was obtained:

```bash
sudo -i
```

## 2. Creating the Python File

The directory used in the previous activities was accessed:

```bash
cd /home/aluno/Documentos/Arquivos
```

The Python file was then created:

```bash
nano arquivo.py
```

The code used was:

```python
def somar(a, b):
    return a + b

def subtrair(a, b):
    return a - b

resultado = somar(5, 3)
print(resultado)
```

The program contains two mathematical functions, `somar()` and `subtrair()`. In the execution flow, `somar()` is called to calculate `5 + 3`.

## 3. Testing the Original Code

Before compilation, the code was executed normally:

```bash
python arquivo.py
```

Output:

```text
8
```

This confirms that the source code was working correctly before being transformed into bytecode.

## 4. Compiling to Optimized Bytecode

Python was invoked with the `-OO` option to generate an optimized bytecode version:

```bash
python -OO -m py_compile arquivo.py
```

After compilation, `ls` was used to check the files:

```bash
ls
```

Output:

```text
arquivo.py  __pycache__
```

The `__pycache__` directory was created automatically by Python to store the compiled file.

## 5. Accessing and Renaming the Bytecode

The bytecode directory was accessed:

```bash
cd __pycache__
```

Its contents were then checked:

```bash
ls
```

The `.pyc` file generated by Python was renamed to `arquivo_ofuscado.py`:

```bash
mv arquivo.cpython-313.opt-2.pyc arquivo_ofuscado.py
```

After this operation, the file in the directory was:

```text
arquivo_ofuscado.py
```

Although the extension was changed to `.py`, the contents remained **compiled Python bytecode**, not the original source code.

## 7. Executing the Obfuscated File

The file was used to execute the program:

```bash
python arquivo_ofuscado.py
```

The recorded result was:

```text
8
```

This was intended to demonstrate that the program remained functional after compilation and renaming.

The recorded execution preserved the original program's behavior, performing the `5 + 3` operation and displaying the result.
