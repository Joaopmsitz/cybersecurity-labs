# Hackers do Bem — Fundamental | Module 04

> Program: Hackers do Bem > Stage: Fundamental > Module: 04 > Status: Activities documented

## Activities

### Activities — Class 13–14

| Activity | Topic | Description | View |
|---|---|---|---|
| 4.01 — Modifying Authentication Control Settings on Kali Linux | Identity and Access Management | Change and validate a user's authentication password on Kali Linux, while examining how user and group information is organized in the /etc/passwd and /etc/group files. | [View](./aula-13-14/atividade-4.01-controle-auth/README.md) |
| 4.02 — Exploring SELinux on Kali Linux | Cybersecurity Practice | Explore SELinux (Security-Enhanced Linux) on Kali Linux and understand how it works as a mandatory access control (MAC) mechanism. | [View](./aula-13-14/atividade-4.02-selinux/README.md) |
| 4.03 — Credential Management with KeePassXC | Cybersecurity Practice | Use KeePassXC to create a password-protected database and store a test credential. | [View](./aula-13-14/atividade-4.03-keepassxc/README.md) |
| 4.04 — John the Ripper: Dictionary Attack | Cybersecurity Practice | Use John the Ripper to perform an offline password audit in a controlled environment, using a password hash stored on the system and a dictionary-based attack. | [View](./aula-13-14/atividade-4.04-john-dicionario/README.md) |
| 4.05 — Windows Credential Manager | Cybersecurity Practice | Explore Windows Credential Manager in Windows Server 2022, identify the different types of stored credentials, and perform a credential backup procedure in a laboratory environment. | [View](./aula-13-14/atividade-4.05-credential-manager/README.md) |

### Activities — Class 15–16

| Activity | Topic | Description | View |
|---|---|---|---|
| 4.06 — Implementing a RADIUS Server on Kali Linux | Cybersecurity Practice | Implement and test a RADIUS (Remote Authentication Dial-In User Service) server using FreeRADIUS on Kali Linux. | [View](./aula-15-16/atividade-4.06-radius/README.md) |
| 4.07 — Exploring Google Authenticator on Kali Linux | Cybersecurity Practice | Configure Google Authenticator on Kali Linux using TOTP (Time-based One-Time Password). | [View](./aula-15-16/atividade-4.07-google-authenticator/README.md) |
| 4.08 — Google Authenticator in Firefox | Cybersecurity Practice | Configure a TOTP authenticator in Firefox using the Authenticator by mymindstorm extension and a secret generated by Google Authenticator on Kali Linux. | [View](./aula-15-16/atividade-4.08-google-authenticator-firefox/README.md) |
| 4.09 — TPM and USB | Cybersecurity Practice | Check whether a TPM (Trusted Platform Module) is available in Kali Linux and identify USB devices available in the laboratory environment. | [View](./aula-15-16/atividade-4.09-tpm-usb/README.md) |
| 4.10 — OTPClient | Cybersecurity Practice | Use OTPClient to store a TOTP secret in a protected database and generate temporary authentication codes. | [View](./aula-15-16/atividade-4.10-otpclient/README.md) |
