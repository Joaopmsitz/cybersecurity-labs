## Module Overview

This module covers Linux authentication and security, password management and auditing, Windows credential storage, centralized authentication, multi-factor authentication, hardware security, and OTP token management.

The module contains ten activities organized into two class groups.

## Skills and Concepts Covered

- Linux user and group management
- SELinux and mandatory access control
- Secure password storage and password auditing
- Windows credential management
- RADIUS and centralized authentication
- TOTP-based multi-factor authentication
- Authenticator applications and token management
- TPM fundamentals and hardware availability in virtual machines
- USB device inspection
- Encrypted databases and credential handling

## Learning Outcomes

Upon completing the documented activities, learners practiced inspecting security configurations, managing authentication credentials, auditing test passwords, configuring centralized authentication, generating and validating TOTP codes, and examining hardware security capabilities in a virtualized environment.

The exercises were performed in controlled laboratory environments. Secrets, passwords, recovery codes, and other sensitive authentication material should not be included in public repository documentation.
