# Activity 4.08 — Google Authenticator in Firefox

> **Program:** Hackers do Bem  
> **Stage:** Fundamental — Module 04  
> **Class:** 15–16  
> **Environment:** Kali Linux and Firefox  
> **Status:** Completed

## Objective

Configure a TOTP authenticator in Firefox using the Authenticator by mymindstorm extension and a secret generated by Google Authenticator on Kali Linux.

The activity demonstrates how the same TOTP secret can be used by different authenticator clients to generate temporary authentication codes.

**Security note:** The TOTP secret, QR code, authentication codes, and recovery codes are not recorded in this README.

## Environment

- Kali Linux — laboratory virtual machine
- Firefox — personal computer
- Authenticator by mymindstorm extension
- Google Authenticator
- TOTP (Time-based One-Time Password)

## Procedure

### 1. Install the Extension in Firefox

In Firefox on the personal computer, the Mozilla add-ons catalog was accessed, and the following extension was searched for:

```text
Authenticator by mymindstorm
```

After installation, the extension was added to the toolbar using the pin option.

### 2. Generate the TOTP Secret on Kali Linux

On Kali Linux, superuser access was obtained:

```bash
sudo -i
```

The following command was then executed:

```bash
google-authenticator
```

The time-based authentication option was selected:

```text
Do you want authentication tokens to be time-based (y/n) y
```

Google Authenticator generated a new TOTP secret and the information required to associate it with an authenticator application.

The generated secret was omitted from this document because it functions as a credential for generating TOTP codes.

### 3. Transfer the Secret to the Personal Computer

The TOTP secret generated on Kali Linux was copied to the personal computer using the virtual machine's clipboard feature.

This step allows the Firefox extension to be configured manually without recording the secret as plaintext in the repository.

**Security consideration:** Transferring a TOTP secret to another device creates an additional location where the credential must be protected. The secret should be transferred securely and never included in repository files, screenshots, or public documentation.

### 4. Configure Authenticator in Firefox

In Firefox, the Authenticator by mymindstorm extension was opened.

The edit option was selected, followed by:

```text
+
```

The configuration was entered manually.

#### Issuer

The following value was used:

```text
Kali Linux
```

#### Secret

The TOTP secret generated previously by the following command was entered:

```bash
google-authenticator
```

The actual secret value is not reproduced in this README.

After saving the configuration, the extension displayed the registered account and its current TOTP code.

### 5. View the TOTP Code

When the Authenticator extension was opened in Firefox, the temporary code generated from the registered secret was displayed.

The code changes periodically according to the interval defined by the TOTP mechanism.

The evidence for this step shows the code being generated directly by the browser extension.

**Security note:** The code shown in the evidence is temporary and must not be reused as a permanent credential. Screenshots should not expose a usable authentication code or the underlying TOTP secret.

## Concepts Practiced

### TOTP

Time-based One-Time Password is an authentication mechanism that generates temporary passwords based on a shared secret and the current time.

In simplified form:

```text
Shared Secret + Current Time
              ↓
         TOTP Algorithm
              ↓
      Temporary Code
```

The authenticator client and the system validating the code must possess the same secret and have sufficiently synchronized clocks.

### TOTP Secret

The secret is the information used by the authenticator to generate codes. Anyone who obtains this secret may be able to generate the same temporary codes.

For this reason, the secret must be treated as a credential and must not be published on GitHub.

### Authenticator in Firefox

The extension acts as an authenticator client capable of storing the secret and calculating TOTP codes directly in the browser.

In this laboratory, the same secret created on Kali Linux was used to configure the Firefox extension.

## Results

The Authenticator by mymindstorm extension was manually configured in Firefox using the TOTP secret generated on Kali Linux.

When the extension was opened, the current TOTP code could be viewed and its periodic renewal observed.

The activity demonstrated the relationship between the components:

```text
Google Authenticator
        ↓
     TOTP Secret
        ↓
Authenticator in Firefox
        ↓
   Temporary Code
```

This exercise also illustrated that different authenticator clients can generate matching codes when configured with the same secret and sufficiently synchronized time.
