# Microsoft Security Certification Labs

A structured collection of lab materials and study resources for Microsoft security certifications.

This directory organizes learning resources by certification, supporting hands-on practice, technical understanding, and exam preparation. It is part of an independent cybersecurity learning portfolio and is not an official Microsoft repository.

## Lab Documentation Standards

Where applicable, each lab write-up should include:

- **Objective:** The security concept or task being explored.
- **Source:** Original repository, training platform, or documentation.
- **Environment:** Systems, services, and authorized scope.
- **Implementation:** Relevant configuration steps, commands, or queries.
- **Evidence and results:** Observations, findings, and validation.
- **Lessons learned:** Limitations, troubleshooting, and conclusions.

Clearly distinguish original work, adapted exercises, and third-party training materials.

## Sources and Attribution

- Link to the original source of imported or adapted materials.
- Preserve applicable copyright notices, licenses, and attribution.
- Do not present third-party lab instructions as original work.
- Check redistribution permissions before publishing copied training materials.
- Consult Microsoft Learn for the current certification objectives and requirements.

## Security and Responsible Use

- Perform practical exercises only in authorized environments.
- Never publish credentials, access tokens, tenant secrets, or sensitive personal information.
- Sanitize logs, screenshots, and configuration files before publication.
- Review cloud resources and remove lab infrastructure when it is no longer needed to avoid unnecessary costs.
- Follow the applicable rules of each training platform.

## Disclaimer

This repository documents independent study and lab practice. It does not represent Microsoft, and the presence of study materials does not imply that a certification has been earned or that every topic has been demonstrated through hands-on experience.
